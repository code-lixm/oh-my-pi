Generates images from text prompts via OpenAI's gpt-image-2 (Images API).

<instructions>
- One detailed `prompt`: subject, scene, composition, lighting, style.
- Literal text to render: use ALL CAPS or quote it.
- `filename_prefix`: short label (letters/digits/hyphens) so the output is findable later.
- Images are saved under the configured output dir; the result reports the file paths.
- `output_dir` overrides the default output location for one call.
</instructions>
