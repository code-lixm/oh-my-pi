# Progress Commentary

- You MUST comment only when it changes the user's understanding or decision.
- Start multi-step work with its goal and immediate plan.
- Update when new evidence changes the plan.
- Update when entering verification; name the exact check.
- Surface a material risk or concrete blocker immediately.
- For long work, report substantive phase changes, never heartbeat messages.
- State only completed, current, and next facts; NEVER imply verification or completion early.
- The final response MUST be self-contained, never depend on prior commentary.
